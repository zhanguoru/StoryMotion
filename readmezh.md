# StoryMotion

一键将图片和音频生成视频。

无需剪辑经验。

无需学习复杂软件。

只需准备图片和配音，即可快速生成完整视频。

---

## 功能特点

✓ 图片转视频

✓ 自动镜头运动

✓ MP3音频同步

✓ 自动时长匹配

✓ 批量处理

✓ MP4导出

---

## 使用流程

1. 选择素材目录
2. 选择输出文件
3. 点击生成
4. 等待完成
