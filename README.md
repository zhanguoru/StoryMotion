# StoryMotion

Turn Images and Audio into Videos in One Click.

StoryMotion is a Windows desktop application designed for creators who want to quickly generate videos from images and narration audio.

No video editing experience required.

---

## Features

✓ Convert images into videos

✓ Automatic camera movement

✓ MP3 audio synchronization

✓ Smart duration matching

✓ Batch processing

✓ MP4 export
